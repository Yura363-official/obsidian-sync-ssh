# ipa-app-download

iOS-приложение для работы с `.ipa`-файлами на iPhone: импорт, инспекция
(разбор `Info.plist`, иконка, версия, bundle id), каталог и подготовка к
установке через **Sideloadly**.

Ставится на iPhone как `.ipa` (через Sideloadly / AltStore), исходники и
релизы — в этом репозитории.

---

## ⚠️ Важно про «сохранить любое установленное приложение в .ipa»

Прежде чем начинать, честно про главное ограничение iOS — это не вопрос
кода, а архитектура системы:

- **На обычном (не джейлбрейкнутом) iPhone извлечь чужое установленное
  приложение в `.ipa` НЕЛЬЗЯ.** Каждое приложение изолировано в песочнице
  и не имеет доступа к файлам и бинарникам других приложений. Приложение,
  поставленное через Sideloadly, живёт в той же песочнице — обойти это
  кодом невозможно.
- Бинарник приложений из App Store дополнительно зашифрован (FairPlay
  DRM). Расшифровать его в памяти можно только с **root-доступом**, то
  есть на **джейлбрейкнутом** устройстве.

Поэтому функциональность делится на две части:

| Возможность | Обычный iPhone (Sideloadly) | iPhone с джейлбрейком |
|---|---|---|
| Импорт `.ipa` из «Файлов» | ✅ | ✅ |
| Инспекция `.ipa` (имя, версия, id, иконка) | ✅ | ✅ |
| Каталог своих `.ipa` | ✅ | ✅ |
| Экспорт `.ipa` установленной программы, которую **ты сам** поставил | ⚠️ ограниченно | ✅ |
| Извлечь **любое** установленное приложение в `.ipa` | ❌ невозможно | ✅ |

Полное извлечение любого приложения описано в [`Docs/JAILBREAK-EXTRACTION.md`](Docs/JAILBREAK-EXTRACTION.md)
и требует джейлбрейка.

## Что уже есть в этом каркасе

SwiftUI-приложение (iOS 16+) со следующим ядром:

- **Импорт `.ipa`** через системный выбор файлов (`Files`).
- **Инспектор `.ipa`**: распаковка архива, чтение `Payload/*.app/Info.plist`,
  извлечение названия, bundle id, версии, минимальной iOS и иконки.
- **Каталог** импортированных `.ipa` (хранится в песочнице приложения).
- **Экран установки** с инструкцией и кнопкой «Поделиться» — чтобы отправить
  `.ipa` в Sideloadly / AltStore.

## Сборка

Проект описан через [XcodeGen](https://github.com/yonaskolb/XcodeGen)
(файл `project.yml`) — так не нужно хранить хрупкий `.xcodeproj` в git.

```bash
brew install xcodegen        # один раз
cd ipa-app-download
xcodegen generate            # создаст IpaAppDownload.xcodeproj
open IpaAppDownload.xcodeproj
```

Зависимости тянутся через Swift Package Manager автоматически (ZIPFoundation).

### Установка на iPhone через Sideloadly

1. В Xcode: **Product → Archive → Distribute → Ad Hoc / Development** — получишь `.ipa`.
   (Или собери через `xcodebuild` — см. `Docs/BUILD.md`.)
2. Открой **Sideloadly**, подключи iPhone по кабелю.
3. Перетащи `.ipa`, укажи свой Apple ID, нажми **Start**.
4. На iPhone: **Настройки → Основные → VPN и управление устройством** →
   доверься своему профилю разработчика.
