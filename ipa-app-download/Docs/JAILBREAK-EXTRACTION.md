# Полное извлечение приложений в .ipa (требует джейлбрейка)

> Эта часть **невозможна на обычном iPhone**. Приложение из App Store
> зашифровано (FairPlay DRM), и расшифровать его в памяти можно только с
> root-доступом. Поэтому «сохранить любое установленное приложение в .ipa»
> работает исключительно на джейлбрейкнутом устройстве.

## Как это делают на практике

Готовые открытые инструменты, на которые стоит опираться (не изобретать
велосипед):

- **[frida-ios-dump](https://github.com/AloneMonkey/frida-ios-dump)** —
  подключается к работающему приложению через Frida, снимает расшифрованный
  бинарник из памяти и собирает `.ipa`. Классический и самый популярный путь.
- **[bagbak](https://github.com/ChiChou/bagbak)** — аналог на Frida,
  удобнее для новых версий iOS.
- **Clutch** — старый инструмент, для современных iOS почти не актуален.

## Общая схема (frida-ios-dump)

Работает с **компьютера**, устройство — джейлбрейкнутое, в одной сети:

1. На iPhone установлен джейлбрейк и **Frida** (через Cydia/Sileo, репозиторий
   `https://build.frida.re`).
2. На компьютере:
   ```bash
   git clone https://github.com/AloneMonkey/frida-ios-dump
   cd frida-ios-dump
   pip install -r requirements.txt
   ```
3. Проброс SSH до устройства (обычно порт 22 или 2222 через USB-туннель).
4. Список приложений и дамп:
   ```bash
   ./dump.py -l                # показать установленные приложения
   ./dump.py <bundle-id>       # снять расшифрованный .ipa
   ```

## Если хочется «прямо на устройстве»

На джейлбрейкнутом устройстве это можно завернуть в собственное приложение
или tweak, который:

1. Читает список установленных приложений через `LSApplicationWorkspace`
   (приватный API — доступен только с обходом песочницы / джейлбрейком).
2. Для выбранного приложения запускает Frida-подобную процедуру расшифровки
   бинарника из памяти.
3. Пакует `Payload/<App>.app` обратно в zip → `.ipa`.

Это заметный объём работы и жёстко завязано на конкретную версию джейлбрейка
и iOS. Практичнее переиспользовать `frida-ios-dump` / `bagbak`, а это
приложение оставить как **менеджер и инспектор** готовых `.ipa`.

## Юридическая заметка

Извлекать и распространять чужие платные приложения — нарушение условий
App Store и, возможно, авторских прав. Делай резервные копии только тех
приложений, на которые у тебя есть права, и для личного использования.
